更新：2026-10-30。所有已确认范围见[整机方案](../整机整体/整机方案.md)。本页合并原硬件选型、电源预算、接口、充电、保护、蜂鸣器和电路调查；只保留一套当前描述。工程候选未等同用户选定；原理图、PCB、完整BOM与样机验证尚未完成。

## 2. 电机驱动、电流采样与PCB

- DRV8323SRTAR×2，SPI、无集成系统Buck、内置CSA，左右各6颗外置N-MOS。每电机3PWM、双低侧电阻，共4个ADC输入，第三相按电流和重建。
- ENABLE上电/复位默认禁能；当前nFAULT合并送双Break，并增加INL硬件锁存屏蔽（见第11节），不能只将PWM拉低当全部MOS关闭；故障解除不能直接恢复力矩。驱动寄存器配置/回读、CSA零偏校准是启动检查。
- 电荷泵、驱动供电/VM去耦、SDO上拉、PWM模式和未用CSA通道/LS_REF按DRV8323手册设计，不能简单把第三相所有检测节点接地。
- CSD17577Q3A×12为MOS电气候选：30 V等级、实际4.5/10 V栅压导通参数及Qg需核对；30 V是否够由最坏钳位和VDS尖峰决定，成本未证实最优。栅阻4.7 Ω仅作预留起点，IDRIVE由波形调整。
- 采样提案：每电机2×10 mΩ、1%、Kelvin/四端、2512级1 W起评估，CSA增益20。0.2 V/A；若有效双向余量假设±1 V，约±5 A测量范围，扣除零偏/摆幅/瞬态后再定；不是电机安全电流。
- 5 A情景下I²R=0.25 W，仍需脉冲与PCB热降额。未定电机不得用相电流范围代替电池/BMS电流，也不得移植航模高KV 2204参数。
- 主板优先四层、连续地参考，功率回路短、局部去耦贴桥；大电流回流不穿过CSA/ADC/IMU参考。SWD、NRST、电源与触发测试点保留。封装、EPAD、栅回路和Kelvin线按原厂要求。

## 3. 电源路径与软开关

以下是落实已定行为的功能提案，不是可直接接线图。保护芯片共口/分口、MOS方向及地关系按准确后缀完整资料落实。

```text
3S电芯 → CW1244保护输出 PACK_PROTECTED
  ├─ 核心电池锁存开关 → TPS563201 → 5V_BAT → 电源MUX
  └─ 电机背靠背开关 → VMOTOR → 双DRV8323/功率桥
                          ├─ 共用制动电阻＋低侧MOS
                          └─ 独立5V_BRAKE → 比较器/必要缓冲
USB VBUS → ESD/总输入限流/防反灌
  ├─ 电源MUX → 5V_SYS → 主板LDO/外围/ESP32扩展
  └─ IP2326 → 受保护充电端 → 电池
```

- 核心电池保持与电机运行开关分开控制，才能在USB下关运行电源而保留OLED/VCOM。USB事件本身不生成电机授权。
- TPS2113A的DRB封装为5 V级MUX候选，不接3S原电池；按实际后缀、电流、切换跌落及反灌核算。核心优先USB，电池保持已生效时拔USB转电池待机。
- 运行开关采用背靠背高侧MOS方向，开通时允许必要双向回生、关闭时隔离；启动涌流/斜率另算，不仅用Buck EN代替总开关。
- 电源键基础锁存＋MCU计时方向：按下可临时唤醒核心检测长按，未满2秒不显示用户开机、不接电机电源；松开撤销临时供电。长按成立才进入正常启动。短按用户可见行为仍为无动作。
- USB下长按关机撤销运行供电/电池保持；菜单重开运行供电同时恢复电池核心保持。MCU复位清除力矩许可，供电锁存可独立保持以显示复位原因。
- 不做8秒硬件强关，不增专用强关芯片。保留BMS及基础按键电路静态消耗，不宣称关机电流绝对为零。
- 关机先撤销力矩并禁能，再断运行电源；制动回路及控制供电始终位于电机母线同侧。USB、调试器、充电地不能旁路低侧BMS；B−/P−/C−不得随意短接。

## 4. 主板、扩展板与负载预算

主板TPS563201DDCR输出5 V，TPS562201DDCR备选，再由LDO生成3V3_MAIN。ESP32扩展板原拟用另一颗TPS563201将主板5 V降为3V3_ESP；其4.5 V输入下限在MUX/线损后缺少余量，保留降压架构但器件待重选，两路3.3 V不并联。扩展板插上随5V_SYS供电，不增加独立GPIO控制电源；其防插拔保护由用户负责，主板仍核查反灌与插入瞬态。

ME6211C33M5G-N与ME6217C33M5G均保留为待核查候选。准确商品手册缺少SOT23-5的功耗/热阻数据，不能仅凭旧家族资料300 mW排除；也不能凭标称500/800 mA宣布持续带载已通过。P≈(5−3.3)I，100/150/200/300 mA分别约0.17/0.255/0.34/0.51 W；不能用“标称500 mA”判定SOT23热能力。对应-N完整资料、稳定电容及实际PCB热阻需确认。若不够，先比较更好散热的LDO封装；改变稳压结构另列工程方案。

| 负载域 | 需要核对 |
| --- | --- |
| 3.3 V MCU | 按当前G431RBI6、频率和外设重算；旧G431的70 mA预算不能直接继承 |
| AS5047P×2 | 建议3.3 V模式，正常运行手册Max 15 mA/颗；OTP供电条件单列，不当正常负载 |
| IMU | 工作模式、3.3 V电流与中断；0.55 mA等典型条件不能当本车最大值 |
| OLED | 准确模块供电/上拉/分辨率/全亮电流；旧50 mA仅占位 |
| LED/上拉/ADC分压 | 蓝绿灯提案约1 mA/颗，按VF与亮度定阻值；其他逻辑逐项统计 |
| FUET蜂鸣器 | 若取3.3 V需计入线圈峰值、鸣叫平均电流及LDO温升 |
| 5 V | LDO输入、WS2812、OLED若取5 V、扩展Buck输入功率与损耗 |

旧166 mA/200 mA、5 V约0.878 A均为混合条件情景，不是新MCU下最坏电流。ESP32供电至少0.5 A能力的原厂建议也不是最大负载保证。Buck电感/输出电容按输入下限、饱和、负载峰值、偏压降容和纹波重算。

## 5. 充电、保护与均衡

电芯已明确普通平头18650，3S、满电12.6 V，循环寿命不作选型要求；不额外要求用户现在提供具体型号。正式限流/充放电前仍核对实际电芯，不能由外形推定安全电流。2500 mAh/节、约27 Wh若用于预算必须标占位，不显示为真实容量；三串容量mAh不相加。总压不保证弱单节状态。

IP2326标准版已定，5 V输入升压给3S充电，EN硬件默认低、MCU控制；3S配置和外围按V1.11，CON_SEL经1 kΩ接地等接法需与准确版本复核。不能混用IP2326_8V8。D+/D−用于MCU原生USB，不直接并接充电芯片DP/DM；首版不做PD/QC申请。

0.5 A电池侧是功率核算起点，不是批准的设置。12.6×0.5=6.3 W，按85%效率示例需USB约1.48 A，另加核心/扩展消耗；普通电脑500 mA输入不能许诺该充电电流。输入限流同时覆盖核心和充电分支；源能力未验证则拒绝启充并显示原因。

充电完成优先使用可靠状态输出并结合电池电压、超时和故障分类；IP2326资料终止电流200～300 mA及系统并联负载影响需实测。输入掉电、超时、过温与EN关闭均不当充满。USB核心可单独启动，但BMS欠压恢复/低电芯充电仍按实际电路处理，不宣称已经解决。

CW1244ALBS负责独立逐节保护、过流/短路/温度及被动均衡，不依赖MCU；IP2326的23/24脚仍悬空，其2S均衡不用于3S。当前公开简版资料不足以冻结准确ALBS后缀的保护MOS、采样、NTC、均衡阻值/电流、延时和恢复接线。这是原理图定稿前需补齐的资料项，不编造参数或抄其他BMS。

电池温度与功率区各留MCU NTC检测方向，BMS温度电路独立核对；10 kΩ/B3950是候选方向，不能未经分析共接两个检测输入。保留逐节测试点、配组核查、断线/短路诊断。BM3451SMDC-T28A、IP3255AAQ已排除；CN3303、BQ77915、S8254/HY2213等仅为历史对照。

## 6. 回生与过压

电机共用母线→制动电阻→低侧N-MOS→同侧功率地。TLV3012B（集成基准、推挽）为优先电气候选；TLV3201＋外部基准为对照。按实际Qg/米勒平台/源灌电流核对直驱，能力不足加缓冲，不默认LM5109。MCU仅监测，不作为硬件耗能动作依赖。

TPS70950从VMOTOR产生独立5V_BRAKE是供电候选，仅供比较器和小驱动；输入范围、散热、基准启动和回生供电建立时间都需核算。芯片可从母线取能不等于断电转轮时及时建立控制。

| 工程起点 | 值与限制 |
| --- | --- |
| 迟滞目标 | 旧13.4/13.0 V提案撤回；改评估约13.8 V导通、13.4 V释放，误差/负载边界见第11节，仍不是投板定案 |
| 制动电阻 | 10 Ω、25 W级脉冲型起评估；13.8 V约1.38 A、19.0 W瞬时，不能保证吸收超过该值的回生 |
| 制动MOS | 可先以CSD17577Q3A核算驱动负载，未定；需实际栅压导通与开关波形验证 |
| 母线电容 | 470 µF/35 V低ESR＋各桥局部陶瓷作为布局额度；并非已证实足够 |

电阻额定功率受安装/散热条件限制，须看脉冲能量及重复热耗散，远离电芯、IMU和塑料。TVS或母线电容不能代替持续回生耗能。按I≈V/R、P≈V²/R、E=∫Pdt、ΔV≈IΔt/C核算；控制供电上电时间须取最坏情况，不能只取比较器传播延时。

迟滞提案：VMOTOR经Rt接IN+，IN+经Rb接地、经Rf接比较器输出形成正反馈，IN−接基准。理想公式V_on=Vref(1+Rt/Rb+Rt/Rf)−VOL·Rt/Rf，V_off以VOH代替VOL；实际加入内部迟滞、误差与负载。ADC分压独立，避免采样扰动比较器门限。验证满电、BMS断开、MCU复位、控制电源异常、双电机同时回生和外力转轮。

## 7. 外围与板间接口

- AS5047P×2：SPI共享独立CS、奇偶校验，建议3.3 V模式，VDD/VDD3V3及去耦按原厂；5 V模式逻辑门限不能默认兼容3.3 V。
- ICM-42670-P：3.3 V逻辑、SPI＋INT，按原厂去耦，远离功率磁场、蜂鸣器及机械应力。
- SSD1315：0.96英寸I²C模块，LVGL驱动层适配；核查实际分辨率、引脚、供电、上拉及初始化，不直接套SSD1306模块参数。
- FUET-8530-3.6V：已选无源电磁，手册额定3.6 Vo-p、范围2.5～4.5 Vo-p、2700 Hz/50%方波条件、电流MAX 100 mA、16±3 Ω。这些不保证本车3.3 V声压或开关瞬时电流。建议3.3 V＋低侧逻辑级MOS，默认关闭、去耦/感性保护按厂家与波形验证，不接MCU直驱或5 V脉冲。表列8.5×8.5×3.0 mm与渠道高度差异需核实，焊盘不按同名8530互换。
- WS2812×4：主板5 V，SN74AHCT1G125电平转换候选，逐颗去耦/首颗串阻/OE默认态与掉电反灌核查；软件限亮不代替硬件峰值预算。
- 蓝绿0603各1：用途见软件，GPIO与阻值未冻；3.3 V蓝灯压差不足时再评估5 V开关驱动。
- Type-C：USB2.0受电设备，CC1/CC2各自5.1 kΩ、接口侧低电容ESD，VBUS总限流/反灌保护；CC下拉不等于允许取3 A。
- 扩展侧HC-PBB08-2-16-M-H1.0-G1-R-P-04已明确；主板母座候选HC-PBB08-2-16-F-H4.0-G1-R-P-04，准确配对/合高/脚号/镀层与封装待核查，不能仅将H值相加。16接点提案5 V×3、GND×5、UART×2、预留×6，按触点额定值和镜像脚号调整。UART掉电反灌/热插拔尚未验证。

## 11. 其余硬件桌面复核（2026-10-30）

本轮获取并核对驱动、MOS、Buck/MUX/LDO、比较器、编码器、IMU、ESP32、蜂鸣器及逻辑器件原厂资料。来源版本/文件SHA256见[资料索引](资料索引.json)。可复现计算与理想逻辑检查：[verify_hardware.py](verify_hardware.py)，运行`python 硬件/verify_hardware.py`，结果为[验证结果.json](验证结果.json)。本轮没有实物、正式网表或SPICE电路，以下“通过”仅限指定计算/逻辑范围。

### 11.1 必须修改的3PWM故障关断

DRV8323表8-3明确：INL=1、INH=0时低侧MOS导通；INL=0时，不论INH如何，GH/GL均低、桥臂Hi-Z。因此，Break令6路PWM变低不等于两桥全部禁能。原先只有Break联动的方案不予通过。

新增锁存提案，不改变6路PWM、两颗独立ENABLE和双Break：

| 连接 | 作用 |
| --- | --- |
| 两颗DRV的nFAULT与独立VMOTOR有效性监测开漏输出合并为FAULT_BUS，3.3 V上拉 | 同时进入TIM1/TIM8 Break与外部锁存清零逻辑；不能默认未供电DRV的nFAULT始终有效 |
| SN74LVC1G11三输入AND候选 | `/CLR = FAULT_BUS AND EN_L AND EN_R`；任一ENABLE低或故障低都清零 |
| SN74LVC2G74单D触发器候选 | D=3.3 V、/PRE=3.3 V、/CLR接上述AND、CLK接PF1；注意它是一位触发器，不是两位 |
| Q→两颗DRV共六个INL | Q=0使两桥Hi-Z；两组INL各设下拉，逻辑失电时仍默认低 |
| PB13/PB14→独立DRV ENABLE | 原有控制保留，各有硬件下拉；EN高可唤醒SPI而Q仍为0，便于配置与故障读回 |
| PF1/F1→PWM_ARM_CLOCK | 改为GPIO输出并下拉；取消BAT_STAT阶段指示采集，不删保护/电压/温度/调试接口，仍零空闲IO |

上电时EN_L/EN_R均低，锁存清零。两DRV唤醒后等待手册SPI就绪（1 ms条件值并留余量），在INL=0时配置3PWM、CSA、锁存故障模式`OCP_MODE=00b`并校准；六PWM及双定时器已准备好、全部授权条件成立后，PF1才发一个新的上升沿。清零释放到该沿留至少1 µs设计裕量，实际按器件时序检查。故障或VMOTOR失效时，Q异步清零；nFAULT/母线自行恢复、USB插拔或数据恢复不能把Q重新置1，必须经过对应的人工/状态机许可再发新沿。意外复位由ENABLE硬件下拉清零；停机也通过ENABLE清零，并按已定时序切运行电源。所有逻辑供电3.3 V，逐颗去耦，CLR/PRE不同时拉低。

独立VMOTOR有效性监测可先评估3.3 V供电的TLV3011B开漏比较器（与制动TLV3012B不同），例如124k/20k分压与1.242 V参考的标称阈值约8.94 V；门限与实际欠压策略、迟滞和快速掉电响应仍待验证。输出并入FAULT_BUS，不增MCU脚。完整BMS资料到位后还应评估其保护动作的可信观测，不能把短暂电源跌落或BMS事件一律假设可由DRV的nFAULT捕获。

已检查启动不误授权、显式授权、故障清零、不自动重启、再次授权、任一ENABLE撤销、VMOTOR失效/恢复及3PWM真值表。只是理想布尔模型通过，供电爬升、清零脉宽、毛刺、六INL负载和实物关断时序仍待验证。准确逻辑后缀/封装与采购价未冻结。

### 11.2 稳压、总负载与USB

已纠正原审查结论：旧ME6211家族V14泛称SOT23功耗300 mW，但用户提供的ME6211C33M5G-N准确商品页对应V22手册，第5页300 mW/410°C/W仅列SOT23-3，缺少M5/SOT23-5条目；不能据此把M5-N直接判为不足。ME6217C33M5G商品页对应V02，第2页1 W只针对SOT89-5，也缺少SOT23-5热参数。两者标称输出电流500/800 mA均覆盖当前约300 mA工程额度，持续温升仍未证明；保留两颗候选，不因这份缺项资料直接决定改DC/DC。

本轮3.3 V工程分配为MCU100 mA、编码器30 mA、IMU5 mA、OLED50 mA、杂项15 mA、两DRV VREF合计6 mA，基础206 mA；加鸣叫平均100 mA为306 mA，LDO约0.520 W。蜂鸣器线圈最小13 Ω在3.3 V下的纯电阻峰值上界约254 mA，总瞬时分配约460 mA；这不是实际线圈波形，不能当持续平均电流。所有分配含占位值，尤其OLED、MCU和IMU不是已测最大值。

替代候选可比较TLV75733PDYDR（带散热焊盘SOT23）/TLV75733PDRVR（WSON），保持已定LDO架构。家族手册支持1 A、VIN 1.45～5.5 V；DYD/DRV的JEDEC热阻分别约92.5/100.2°C/W，不能把EVM的DYD 60.3°C/W套到普通DBV。0.520 W、环境50°C时，按100.2°C/W情景估Tj约102°C；最坏输入/输出误差、板内环境60°C及0.6 W以上热耗散会接近限值。需要焊盘/铜皮设计和实测，未以该估算冻结型号或价格。

主板TPS563201在3S→5 V的输入范围可继续；5 V原厂LC建议L=3.3～4.7 µH、有效C=20～68 µF。54.9k/10k＋0.768 V参考的标称输出约4.984 V；12.6 V、3.3 µH、580 kHz情景电感纹波约1.576 A峰峰值。按实际负载峰值和电流限制选饱和/温升能力，不以3 A输出标称选一颗仅3 A饱和的电感。

扩展板TPS563201不能直接判通过：USB端4.75 V，经MUX 1.5 A×150 mΩ及额外0.1 V线/保护压降，仅剩4.425 V，低于4.5 V推荐输入下限。保留5→3.3 V降压架构，重新比较低输入下限Buck；TPS62133的3～17 V、3 A仅作为电气对照候选，成本/采购及外围尚未冻结。

TPS2113A必须使用所评估的DRB封装，不能混用PW的1.25 A档；DRB可调到2 A，但限流误差与热态压降必须核查。例如手册RILIM=400 Ω时标称1.25 A、范围0.95～1.56 A，不能把标称值当保证输出。两路输入只接5 V级电源，禁止3S直接进入。主电池/USB切换压降、保持电容、逆灌和限流未通过台架验证。

按本轮分配、4颗WS2812各60 mA占位、ESP32 3.3 V/0.5 A及85%效率，5 V域约0.949 A；0.5 A电池充电在12.6 V另需USB约1.482 A，合计约2.432 A。若USB4.75 V、效率80%、电池充电上偏至0.55 A且ESP32按1 A情景，合计约3.253 A，连3 A源也不够。1.5 A源在核心占1 A时，只剩约0.169 A电池充电功率。不能将“5 V/3 A”当任何功能组合都可同时打开的保证。

普通电脑USB不能承诺同时带ESP32、全亮灯和充电。USB总限流要在充电与核心分支之前，MUX只限制核心支路；IP2326输入欠压环也不等于USB源授权/总电流限额。扩展板仍按用户要求直接取5V_SYS，不新增独立主控电源开关，因此必须明确扩展固件低功耗启动约定，并核查枚举前负载、插入浪涌和低能力源场景；本项仍未通过。

### 11.3 充电、保护与状态可观测性

IP2326 V1.11确认CON_SEL经1k到地选3S、VSET悬空对应12.6 V、RISET=180k对应0.5 A（电池端，手册±10%）；0.5 A仍只是起算值，需按实际电芯批准。DP/DM不接USB数据线：芯片在3S电压升高后会尝试申请7/9 V，不能让它与MCU原生USB共线；首版不使用快充协商，具体未用引脚接法仍需核对。

NTC与状态必须单独处理：资料示例100k/B4100并82k属于特定保护窗口，文中约45°C减流、55°C停充；不能把它当任意18650都合适，也不能把通用10k NTC直接代入。MCU/BMS/充电芯片的独立激励不能共接一个NTC节点；按实际电芯允许温度重新设计硬件窗口，MCU暂定10～40°C不能替代硬件窗口验证。

LED亮/灭/闪可描述充电、停止和异常；BAT_STAT仅描述涓流/恒流，本轮不再采集。没有可靠BMS状态时，LED灭＋总压正常仍不能严格证明正常充满：保护MOS断开、弱单节先过压或负载断开可能造成歧义。未补可信的BMS状态/单节观察或等效判据前，界面应显示“充电已停止/原因待确认”，不把所有停充显示成“已充满”；整机“正常充满可正确显示”验收项仍未通过。

CW1244公开V1.5只有简版功能/框图：ALBS可解析为A功能版本、L锂离子、B参数型、S封装型，但B型准确阈值/延迟和完整接线没有得到证明。不得用家族阈值范围代替B型配置，不得抄其他后缀补齐外围。三串均衡、过温/断线、保护MOS与恢复路径继续作为定稿阻塞项；IP2326的23/24脚仍不作3S均衡使用。

### 11.4 驱动、采样与共用SPI

10 mΩ×20=0.2 V/A可继续作为测量提案；5 A时每个电阻0.25 W。CSA增益约±3%、分流电阻±1%叠加约±4.03%，4 mV输入零偏折算0.4 A，必须校准，电流正负号也需按接线核对。DRV手册增益20、0.5 V阶跃到±1%的600 ns是条件/典型值，不是包括MOS换向、RC和ADC采样的总最坏时间；另加100 Ω/1 nF滤波本身到1%就约0.461 µs。因此第10节的1 µs边沿保护只是待实测假设，不能用“600 ns<1 µs”宣告4 µs窗口已保证。

特别纠正：SEN_LVL最低0.25 V在SP输入上的保护，10 mΩ对应25 A；默认1 V约100 A，均与CSA增益20无关。它不是5 A保护。VDS保护随MOS导通电阻、温度和门限误差变化，也不能直接当精确5 A。实际电机/电芯未知前，保留软件限流、独立故障锁存、VDS/VSENSE保护，并补充可验证的过流门限与响应设计，禁止以测量范围代替保护阈值。

CSD17577Q3A手册10 V栅压RDS(on)最大约4.8 mΩ、4.5 V约6.4 mΩ，Qg(10 V)最大约35 nC；3颗高侧20 kHz的平均栅电荷电流约2.1 mA，低于DRV所列25 mA平均高侧能力，但仍需看低电池电压、温度、死区和IDRIVE。栅阻4.7 Ω不是最终值；30 V VDS尖峰及热设计未通过，35 A封装标称不能当本车相电流。

编码器SPI1保持Mode 1、170MHz/32=5.3125 MHz；AS5047P上限10 MHz，CS建立与帧间高电平均至少350 ns。两片按读命令＋后续返回帧估64时钟，加4段350 ns约13.45 µs，属于通信时长估算而非总控制执行时间；需处理流水返回、奇偶和ERRFL。

SPI3的DRV采用Mode 1并降到/128=1.328125 MHz，SDO先按2.2k上拉、50 pF总线电容情景，升至0.7VDD约132 ns；再加30 ns数据延迟及20 ns采样裕量，小于半周期376 ns。电容、IMU下拉驱动能力及实际波形仍需核查。IMU默认支持Mode 0/3，可先按默认模式配置，再通过DEVICE_CONFIG.SPI_MODE切到Mode 1/2（CS释放后生效），运行时选Mode 1；仍为四线SPI。TDK资料明确未选中时SDO高阻，电气结构允许共享，不代表不同设备帧/速率/片选的软件已实现。

### 11.5 再生制动不能提前判通过

TLV3012B除参考误差外还有输入失调、2～8 mV内部迟滞（6 mV典型）和温漂。旧13.4/13.0 V中心值余量不足，保守角落计算释放点可能低至约12.51 V，存在满电母线制动后不释放的情景，因此撤回旧中心值。

新提案采用Rt=100k、Rb=10k、Rf=1.5M（0.1%）与5 V输出假设，含6 mV典型迟滞时约13.778 V导通、13.378 V释放，即约13.8/13.4 V。脚本按参考额外±1%温漂、等效失调/CMRR±12mV、输出摆幅与电阻角落给出约13.24～14.29 V导通、12.86～13.92 V释放的保守设计包络；不是原厂联合最坏值保证。若按电池最高12.7 V设计，最低释放点仍有约0.16 V余量，但需连同充电最高电压和纹波重新确认。

TPS70950的VIN可到30 V，但EN推荐最大6.5 V，**不得把EN直接接VMOTOR**；手册允许EN悬空使能。其5 V版本启动最大1.5 ms是在手册指定负载/电容测试下；TLV3012B上电时间1.9 ms是典型值，不能只按数微秒传播延迟算启动。以VMOTOR起点6 V、回生2 A、5 ms未耗能、470 µF下偏20%的情景，电容模型升到约32.6 V，已经超过30 V MOS等级。这不是本车实测回生量，而是说明原容量/启动组合没有保证。

需要核查从VMOTOR自供电的全失电冷启动，以及核心有电时是否通过隔离供电提前保持制动控制就绪；另评估短脉冲钳位/更快启动/增加有效母线容量。比较器直接推35 nC级MOS也未通过，需核查负载下的反馈摆幅和栅充电，必要时加小逻辑缓冲。冷启动测试通过前，不冻结TPS70950＋TLV3012B组合。

10 Ω在13.8 V只吸约1.38 A、19 W；若回生源持续2 A，即使MOS全开也会趋向20 V而非13.8 V。实际电机、转速、转动惯量和BMS吸收状态未知，无法冻结阻值和脉冲能量。25 W额定依赖安装散热，TVS不得代替持续耗能。回生电阻、MOS、独立控制供电、母线电容与必要钳位均须在BMS断开、双电机同回生和外力转轮时验证。

### 11.6 外围与结构边界

AS5047P的3.3 V供电/逻辑可用，按3.3 V模式正确连接VDD与VDD3V3并去耦；两颗编码器按15 mA/颗计预算。磁场要求约35～70 mT；手册时序/精度参考磁铁为N35H、直径8 mm/厚3 mm，不等同用户磁铁选型。气隙、轴心和实际磁铁均未确定，结构需可调整并读DIAAGC诊断后验收。

ICM-42670-P的VDD/VDDIO均1.71～3.6 V，3.3 V兼容，SPI最高24 MHz；0.55 mA是特定低噪声典型条件，本轮5 mA仅工程额度。去耦、滤波延迟、数据就绪与陀螺/加速度量程须随实际控制确定。

FUET确认2700 Hz/50%、3.6 Vo-p额定、工作2.5～4.5 Vo-p、16±3 Ω及最大100 mA条件。继续3.3 V驱动方向，采用2.5/3.3 V栅压有导通保证的小MOS，不能因主桥MOS有4.5 V参数就直接拿来当3.3 V蜂鸣驱动。设计去耦、续流/钳位及默认关断后测声压和电流，不用额定平均值替代瞬时预算。

SN74AHCT1G125的4.5～5.5 V供电、VIH最小2 V支持3.3→5 V数据转换；零GPIO余量下/OE可硬件接低、A下拉使复位数据为低，不虚构独立OE控制脚。WS2812数量已定，准确版本的通道电流/时序仍待确定；四颗×60 mA是保守占位。OLED准确模块供电、I²C上拉和分辨率未知，尤其模块若把上拉接5 V，必须核对/修改而非默认直接接MCU。

VBAT/VMOTOR分压在MCU失电时仍可能注入3.3 V域；须核对掉电注入、必要的随3.3 V自动断开的检测开关和ADC源阻抗/RC，不能只凭大电阻宣称软关机无反灌。3S高侧MOS也不得直接由3.3 V GPIO拉栅，需相对源极的默认关断、栅压钳位及电平转换。核心锁存、MUX、运行开关目前没有正式网表，因此复位保持、USB优先和BMS地不被旁路仅是功能要求，尚未完成接线级验证。

## 13. ESP32电源与USB充电许可细化

### 13.1 扩展Buck的可核对候选

本轮核对TI的TPS62821/22/23家族手册：TPS62822为2 A，TPS62823为3 A，VIN推荐2.4～5.5 V，输出可调0.6～4 V，支持100%占空比；DLC为2×1.5 mm、8脚VQFN。它们可以进入5V_SYS→3.3V_ESP的候选池，重点评估4.0～4.4 V实际输入下的1 A瞬态情景，避免原TPS563201的4.5 V输入下限。100%占空比不具备升压能力，不能把“最低输入2.4 V”理解成此时仍输出3.3 V。

手册LC起点为0.47 µH，亦允许1 µH；输出典型2×10 µF或22 µF，至少5 µF有效容量，输入至少3 µF有效容量。ESP32方案先预留22～47 µF输出额度、靠近模组的去耦和必要输入储能；电容直流偏压降容、LC允许组合、感值偏差/饱和/DCR、供电软启动及插入浪涌需要按准确料号完成。EN可随供电固定使能，保持用户要求的“插上即随5V_SYS供电”，不增加主控独立电源开关；PG先保留测试点，不占新GPIO。

TPS62822/23尚未冻结：搜索服务本轮503，商城搜索返回反爬/无商品数据，未取得可核实的国内散料数量档价格/库存。不能据此宣称它们比TPS563201或TPS62133更便宜、更好买。当时AP63203原厂请求403，未用记忆参数把它加入已核验候选；后续重试成功，已核验的宽压候选及更新结论见第14节，渠道仍未核实。后续采购比较仍以小批总成本（含电感电容）为准，而非只看芯片预算价。

### 13.2 固定0.5 A充电的许可策略提案

当前ISET=180k的0.5 A是电池侧起算值，并有±10%资料误差，不是MCU可随意调节的USB输入电流。未增加可验证的电流调节硬件前，界面不提供虚构的“0.1/0.2/0.5 A软件设置”。

| USB与扩展状态 | 本轮策略提案 |
| --- | --- |
| 普通电脑USB、来源能力不明或确认仅1.5 A | 固定0.5 A电池充电禁止；保留符合输入能力的核心调试，扩展负载仍需约束 |
| 用户本次接入明确确认5 V/3 A、无扩展板并由用户确认 | 电池/温度/电机禁能及电源路径检查通过后，才接受本次手动启充请求 |
| 确认5 V/3 A、有扩展且安静模式已确认 | 无线关闭/限制，ESP32按3.3 V侧≤0.3 A工程包络核算；实际模式须测量通过，再允许手动启充 |
| 扩展存在但固件未响应、安静状态未知或无线重负载 | 不启充；不能把UART无响应自动解释为未插扩展 |
| 充电中电压跌落、温度/电池异常或扩展退出已验证模式 | 关CHG_EN并报原因，恢复后仍需人工请求，不自动反复启充 |

输入能力确认按每次USB接入会话处理，不复用上一次充电头设置；电压正常或USB未枚举都不能证明3 A能力。没有扩展存在检测脚时，“无扩展”必须来自用户明确确认，或后续另行验证的可靠检测，不能仅靠超时猜测。该策略没有改变扩展板直接供电的硬件要求。

按连接器VBUS 4.6 V、共同保护路径另降0.1 V、核心MUX按1.5 A×150 mΩ及支路线损0.1 V分配，IP2326输入取4.5 V、ESP32 Buck输入取4.175 V；再按效率80%、电池侧0.55 A上偏、主板基础206 mA（不含蜂鸣）、WS2812仍按4×60 mA瞬时占位、ESP32 3.3 V/0.3 A及另外0.1 A裕量，计算约2.78 A。ESP32若按1 A情景，约3.47 A，超过3 A。0.3 A是待实测的充电安静模式负载包络，不是把ESP32稳压器额定能力降到0.3 A；其电源仍需满足原厂至少0.5 A供电能力及瞬态要求。因此“3 A源”也必须配合已验证的扩展模式和负载边界，不能一律放行。充电期间不发普通按键提示音；故障提示、充满提示在关CHG_EN后再鸣叫，保留故障提示不可静音的要求。

理想许可逻辑已检查：低能力源、来源未确认、扩展未知、电机未禁能、温度/电池异常、电压不足与电源路径未验证均拒绝。仅在所假定前提全部成立时允许手动请求。此为计算/决策模型，尚未实现真实ESP32协议、总输入限流、CHG_EN互锁或供电实测；没有把3 A电源视为已经验收。

### 13.3 VBUS需要可测电压，而不只是有/无

PC2/D3在G431准确封装中支持ADC1_IN8，本轮由普通GPIO存在检测改为VBUS_ADC，球位数量不变。ADC1慢速规则组增加VBUS采样，暂分配DMA2_CH3/ADC1请求，DMA共9/12通道；电流注入组仍保持两ADC、双秩同步采样。实际规则/注入组仲裁、VDDA/VREFINT校准和DMA驱动仍未实现。

可先评估VBUS经100k/47k（0.1%）分压、节点10 nF滤波，连接器5.5 V时节点约1.76 V；这是检测提案，不能代替输入过压保护。未供电反灌/ADC保护仍需按第11节处理。待误差/响应校准后，评估“≥4.8 V稳定1秒才允许请求、<4.6 V持续20 ms停止充电”的门限；USB拔出还要及时撤销许可，具体检测期限按控制安全要求落实。当前阈值是设计起点，不是已保证的准确检测范围。

这些采样只能观察电压，不能证明充电头可供多少电流；总限流仍应覆盖核心和充电两支路。相应功能没有集成进MCU资源探针，旧编译体积不作为新增完整驱动/状态机已装下的证据。

### 13.4 同一低压问题也影响WS2812电平缓冲

只换ESP32 Buck还不够证明整条5V_SYS合格：SN74AHCT1G125原候选推荐VCC最低4.5 V，同样不能在4.4 V系统轨上直接宣称符合规格。可比较工作范围1.8～5.5 V的SN74LV1T125，其输出跟随VCC、支持3.3→5 V翻译，作为较低系统电压下的缓冲候选；准确VCC下输入门限、输出驱动、WS2812版本门限/时序和掉电条件仍须验证，不宣称无条件替换。也可以通过减小MUX/保护路径损耗、确认5V_SYS始终≥4.5 V来保留AHCT；不能仅靠增大电容解决持续压降。

新增依据：[TPS6282x原厂手册](https://www.ti.com/lit/ds/symlink/tps62823.pdf)、[SN74LV1T125原厂手册](https://www.ti.com/lit/ds/symlink/sn74lv1t125.pdf)。候选仅完成电气资料核对，价格/库存和台架结果仍空缺。

LMR36510虽然推荐最高65 V、绝对最大70 V，但推荐最低4.2 V且只有1 A，无法覆盖4.175 V预算情景，本项目不优先。此前TPS62822/23仅适用于受限的5 V支路，最高5.5 V，不能直接接3S；TPS62133推荐最高17 V，仍可用于受控母线，但不是本轮追求更宽耐压的首选。

本轮建议先核价AP63300WU-7（可调、两路复用）和AP63203WU-7（固定3.3 V扩展板），需要更大母线余量再比较AP64350SP-13；TPS62933和LMR33630保留备选。此排序基于电气适配与外围，不是已经证实的价格排序。搜索服务503、商城搜索无有效商品数据；未取得准确散料数量档人民币报价/实时库存，因此不写未经验证的价格或宣称现货充足。
