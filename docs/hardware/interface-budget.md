# 接口与采样预算

更新日期：2026-10-22。仅为功能信号预算，**不是最终 MCU 引脚映射**。

## 当前基线

一颗 MCU 控制两个电机；按用户提出的 **总计 6 路 PWM**预算，即每颗 DRV8323 使用 3PWM。若后续软件/同步采样验证确实要求 6PWM，才改为每电机 6 路、总计 12 路，并重新确认资源。

每电机采用两个低侧采样电阻，共四个；各用 DRV8323 内置 CSA 的两路，接 MCU 四个 ADC 输入。第三相电流由 MCU 按 ia+ib+ic=0 重建，计算量不是改三电阻的理由。阻值、增益和 PWM 有效采样窗口尚未确定。

## 已明确功能的引脚数量

为避免先假定总线共用，下面按编码器、IMU、驱动器三组 SPI 分开计数；这是保守预算，不能据此宣称需要三个独立 SPI 外设。

| 功能 | 信号 | MCU 功能引脚数 |
| --- | --- | ---: |
| 两电机 PWM | 左右各 3PWM | 6 |
| 双电阻电流采样 | 左右各 2 路 ADC | 4 |
| AS5047P×2 | SCK/MOSI/MISO＋2 CS，共享编码器总线 | 5 |
| DRV8323S×2 | SCK/MOSI/MISO＋2 CS，共享驱动总线 | 5 |
| ICM-42670-P | 四线 SPI＋INT1 | 5 |
| SSD1306 OLED | I²C SCL/SDA | 2 |
| WS2812×4 | 菊花链 DATA | 1 |
| 功能按键×2 | 两路输入 | 2 |
| ESP32 扩展板 | UART TX/RX | 2 |
| USB Device | D+/D− | 2 |
| 手动充电 | CHG_EN | 1 |
| **以上小计** | 含模拟与 USB 专用功能脚，不等于可任意使用的通用 GPIO | **35** |

复位按键连接 NRST，单独计 1 个复位脚，不占上表普通功能脚。SWDIO/SWCLK 建议再预留 2 个调试脚（合计 37 个功能/调试脚，另加 NRST）；电源、地、晶振、BOOT 等按最终 MCU 封装另核对。

保护与检测按用户要求放在后面讨论，尚未计入上述小计：驱动 ENABLE/nFAULT（建议各独立、共 4 脚）、母线电压、温度、充电状态、USB VBUS 检测、硬件故障联动、软开关/制动耗散等。不得将 35 或 37 当成整车最终 IO 数。

## 总线与时序

- 两编码器共用一组 SPI、分别 CS，不使用 ABI/ABZ/UVW；转速可由角度差分和滤波计算。编码器板常规信号为 SCK、MOSI、MISO、CS，另加电源/地。
- IMU 与编码器若共享 SCK/MOSI/MISO，可少用 3 脚，上表变为 32；三组全共享理论可少 6 脚、变为 29，但都尚未批准为最终接线。
- DRV8323 SDO 为开漏；总线共用前需核对上拉、上升时间、SPI 模式切换、片选释放、时钟及任务调度，不能只凭同为 SPI 就连在一起。
- 两组 PWM 的同步、ADC 注入触发、双电机交错采样和有效窗口必须验证。低侧双电阻不能在任意 PWM 时刻得到有效两相电流。
- 不再为 MCU 内部运放额外分配采样输入；CSA 在 DRV8323 内，但仍需要四路 ADC 信号。
- DRV8323 CSA 增益可选 5/10/20/40 V/V；采样电阻、双向输出摆幅、RC 建立时间、偏置校准及功耗一起核算。
- WS2812 需核对具体批次的输入高电平门限；若以 5 V 供电，3.3 V 数据能否直驱须查规格，必要时加电平转换。选用定时器/DMA方案时一并计资源。
- NRST、SWD 和 USB 的封装复用，不能在实际 pin map 中重复分配。

最终 MCU 选择需同时满足封装引脚复用、PWM/ADC 触发、USB、总线/DMA、双 FOC 执行时间、Flash/RAM 和成本；STM32G431RBI6 仍只是候选。
