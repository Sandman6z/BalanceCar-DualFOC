# 接口与采样预算

## 当前驱动子系统初步预算

仅为数量预算，**不是最终 MCU 引脚映射**。

| 信号 | 双路 3PWM | 双路 6PWM |
| --- | ---: | ---: |
| PWM | 6 | 12 |
| 独立 ENABLE | 2 | 2 |
| 独立 nFAULT | 2 | 2 |
| 驱动 SPI 三线＋独立片选 | 5 | 5 |
| 双/三电阻方案的电流 ADC | 4～6 | 4～6 |
| 小计 | 19～21 | 25～27 |

还需加入编码器、IMU、母线电压、温度、UART/CAN、按键、LED、SWD、晶振，以及最终选定的电源管理和扩展信号。CAL、BKIN 等另核算。未经时序验证不能以共享总线为由直接扣减资源。

## 接口约定与待验证项

- 两颗驱动共用 SCLK/MOSI/MISO，各自独立 CS，CS 外部上拉；能否与编码器和 IMU 共线仍需核对模式、时序、SDO 释放、上拉和负载。
- ENABLE 分别控制并外部下拉；复位、掉电和高阻时保持禁能，初始化期间不产生有效力矩。
- 两路 nFAULT 分别接可中断 GPIO，并各自上拉至 3.3 V；10 kΩ 仅为评估起点。不能将 nFAULT 拉低一概解释为功率桥已关闭。
- 优先核对 TIM1/TIM8、实际封装复用、同步 PWM 和 ADC 触发；最终接线按所选 MCU 完整型号核对。
- 优先评估 3PWM 以节省 IO；如软件或采样需要 6PWM，再重新预算。输入真值表和其余控制输入不能省略。

## 电流采样

双/三电阻低侧采样优先评估，单电阻仍可按软件支持和时序可行性评估，拓扑未冻结。SOA/SOB/SOC 接 ADC，SPI 不传实时相电流。G431 只有两个 ADC，必须验证双电机交错或其他可行采样安排。

DRV8323 CSA 增益档位为 5、10、20、40 V/V。阻值、增益、双向摆幅、零偏、噪声、功耗和 RC 建立时间一起核算。阻值与增益尚未确定。

最终交付应包含全功能引脚表、每条信号的复用与电平、PWM/ADC 触发时序、总线事务安排，以及软件编译和执行时间证据；当前这些尚未完成。
