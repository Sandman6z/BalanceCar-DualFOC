# 接口与采样预算

更新日期：2026-10-26。仅为功能信号预算，**不是最终 MCU 引脚映射**。

## 当前基线

一颗 MCU 控制两个电机；按用户提出的 **总计 6 路 PWM**预算，即每颗 DRV8323 使用 3PWM。若后续软件/同步采样验证确实要求 6PWM，才改为每电机 6 路、总计 12 路，并重新确认资源。

每电机采用两个低侧采样电阻，共四个；各用 DRV8323 内置 CSA 的两路，接 MCU 四个 ADC 输入。第三相电流由 MCU 按 ia+ib+ic=0 重建，计算量不是改三电阻的理由。阻值、增益和 PWM 有效采样窗口尚未确定。

## 已明确功能的引脚数量

为避免先假定总线共用，下面按编码器、IMU、驱动器三组 SPI 分开计数；这是保守预算，不能据此宣称需要三个独立 SPI 外设。

| 功能 | 信号 | MCU 功能引脚数 |
| --- | --- | ---: |
| 两电机 PWM | 左右各 3PWM | 6 |
| 双电阻电流采样 | 左右各 2 路 ADC | 4 |
| AS5047P×2 | SCK/MOSI/MISO＋2 CS，共享编码器总线 | 5 |
| DRV8323S×2 | SCK/MOSI/MISO＋2 CS，共享驱动总线 | 5 |
| ICM-42670-P | 四线 SPI＋INT1 | 5 |
| SSD1315 OLED | I²C SCL/SDA | 2 |
| WS2812×4 | 菊花链 DATA | 1 |
| 普通 0603 LED×2 | 暂按两路独立 GPIO 预留，蓝色、绿色各一颗；用途见交互提案，接法待核算 | 2 |
| FUET-8530-3.6V无源电磁蜂鸣器×1 | 预留一路定时器PWM输出，开关驱动及供电待设计验证 | 1 |
| 母线电压监测 | 分压/滤波至 ADC，参数待定 | 1 |
| 功能按键×2 | 两路输入 | 2 |
| ESP32 扩展板 | UART TX/RX | 2 |
| USB Device | D+/D− | 2 |
| 手动充电 | CHG_EN | 1 |
| **以上小计** | 含模拟与 USB 专用功能脚，不等于可任意使用的通用 GPIO | **39** |

复位按键连接 NRST，单独计 1 个复位脚，不占上表普通功能脚。SWDIO/SWCLK 建议再预留 2 个调试脚（合计 41 个功能/调试脚，另加 NRST）；电源、地、晶振、BOOT 等按最终 MCU 封装另核对。

以下保护与检测仍未计入上述小计：驱动 ENABLE/nFAULT（建议各独立、共 4 脚）、温度、充电状态、USB VBUS 检测、硬件故障联动、软开关等。不得将 39 或 41 当成整车最终 IO 数。

电池保护与均衡芯片本轮已选择 CW1244ALBS；独立保护及均衡不以 MCU 软件正常运行为前提，不因选了该芯片自动增加 I²C/SPI 引脚。是否额外引出电池状态、逐节电压监测或电源开关控制仍待设计，当前不擅自计入或扣除 IO。

## G431RBI6资源可行性初评（2026-10-28）

后续需求变更：用户于2026-10-28明确使用LVGL并要求更宽松的MCU资源，允许跨系列。以下仅为此前精简菜单场景分析，不再作为当前首选依据；新预算见[整合提案LVGL章节](../project/remaining-design-proposal.md)。

原场景结论：精简首版的软件内存预计可装下、控制外设种类具备；引脚及双电阻ADC时序仍是主要约束。尚无完整UFBGA64球位分配、实际固件编译或双FOC计时，不能称已证明整车够用。

硬件基线为170 MHz M4F、128 KB Flash、32 KB SRAM、TIM1/TIM8、两个ADC、三组SPI、USB FS与12路DMA。RAM由16 KB SRAM1、6 KB SRAM2和10 KB CCM组成；数据手册§3.5明确CCM在0x20005800有系统总线别名，可由DMA1/DMA2访问，不能套用其他STM32系列“CCM一律不可DMA”结论。具体链接与缓冲区地址按访问路径安排。

仅作RAM设计额度：双FOC与校准4 KB、姿态/平衡2 KB、USB CDC及缓冲4 KB、UART/SPI/其他缓冲2 KB、OLED帧缓冲1 KB（仅按128×64、1 bit情景，实际模块分辨率未核定）、灯/菜单/故障记录3 KB、主栈与中断栈合计4 KB，总额度20 KB，目标至少留下约12 KB。额度不是实现测量，不把控制状态与栈重复计算；禁用无界日志/动态分配，不引入大字库、完整图形框架或大波形录制。Flash以应用加字库/参数不超过约100 KB作为工程目标；具体底层/USB库能否达到以release构建及链接map为准，不承诺实际占用。

引脚按本轮提案把IMU与驱动共用SPI后，原39脚减3为36；再加SWD2、驱动ENABLE/nFAULT4、电池及板温ADC2、VBUS检测1、充电状态至少1、电源键/核心保持/运行开关暂估3，为49个功能/调试信号。若使用HSE另需2，NRST另列1。此数目已接近该封装约52个IO口资源，且NRST/晶振/特殊脚是否计入及可用能力以球位表为准，不能直接按52−49计算剩余任意GPIO。充电状态多路、比较器状态、故障联动或额外供电握手若独立引出还会增加。

推荐先做完整球位与AF表：PWM优先TIM1/TIM8；两ADC各取一相同时采样并在有效窗口服务左右电机，注入触发/序列切换/过采样不能靠通道数猜测。蜂鸣器和WS2812占用其他定时器/DMA；共享SPI要证明模式切换、SDO开漏和时序可行。若球位冲突，先检查已允许的总线共享与合理的非实时状态检测接法；不删SWD、故障保护或改动已定双电阻架构来凑脚。

依据：[ST DS12589 Rev6，存储、外设及UFBGA64球位/AF表](https://www.st.com/resource/en/datasheet/stm32g431rb.pdf)。前述内存预算和49脚汇总是本车工程估算，不是原厂给出的整车资源保证。

## 总线与时序

- 两编码器共用一组 SPI、分别 CS，不使用 ABI/ABZ/UVW；转速可由角度差分和滤波计算。编码器板常规信号为 SCK、MOSI、MISO、CS，另加电源/地。
- IMU 与编码器若共享 SCK/MOSI/MISO，可少用 3 脚，上表变为 36；三组全共享理论可少 6 脚、变为 33，但都尚未批准为最终接线。
- DRV8323 SDO 为开漏；总线共用前需核对上拉、上升时间、SPI 模式切换、片选释放、时钟及任务调度，不能只凭同为 SPI 就连在一起。
- 两组 PWM 的同步、ADC 注入触发、双电机交错采样和有效窗口必须验证。低侧双电阻不能在任意 PWM 时刻得到有效两相电流。
- 不再为 MCU 内部运放额外分配采样输入；CSA 在 DRV8323 内，但仍需要四路 ADC 信号。
- DRV8323 CSA 增益可选 5/10/20/40 V/V；采样电阻、双向输出摆幅、RC 建立时间、偏置校准及功耗一起核算。
- WS2812 需核对具体批次的输入高电平门限；若以 5 V 供电，3.3 V 数据能否直驱须查规格，必要时加电平转换。选用定时器/DMA方案时一并计资源。
- NRST、SWD 和 USB 的封装复用，不能在实际 pin map 中重复分配。

最终 MCU 选择需同时满足封装引脚复用、PWM/ADC 触发、USB、总线/DMA、双 FOC 执行时间、Flash/RAM 和成本；STM32G431RBI6 仍只是候选。

新增四个预留功能脚使原 35 脚基线变为 39，含 SWD 为 41，NRST 另计；LED 若改为电源指示等接法需重算。共用制动支路由硬件比较器＋基准＋迟滞自动控制，不默认占 MCU 制动 PWM。MCU 的母线 ADC 已计入本表；比较器状态输入或额外硬件故障联动若需要，另行计数。

USB数据接口已明确用于VCOM调试，预计原生USB CDC实现，不因此另增加一组MCU UART。扩展板连接器为一对配合座，扩展侧HC-PBB08-2-16-M-H1.0-G1-R-P-04，主板供5 V及共地，原UART TX/RX保留；连接器脚号与冗余电源地脚待核算，不直接按连接器16脚追加MCU功能脚。长按软开关的按键检测/供电保持和VBUS检测需补入最终IO，不默认复用既有功能键。

独立电源按键已确认额外增加，不复用两个功能键；实体按键共四个（含NRST）。原39脚小计尚不包含软开关的按键检测、供电保持/关机握手等接口；所需GPIO数量按最终软开关电路确定，不机械地将小计改为40。

2026-10-27扩展板供电确认：不需要MCU/OLED单独控制扩展板电源，不为此增加主板可控电源开关或控制GPIO。扩展板直接取主板5V_SYS；该电源域有电时，扩展板插上即供电，随核心电源域通断。用户负责扩展板端插拔防护设计；主板侧仍需核查连接器、供电预算、插入瞬态对核心供电的影响及断电信号反灌，整套接口的热插拔能力尚未验证。两路3.3 V继续不并联。

2026-10-27批量补充：意外复位后待机、按功能键检查恢复；电池待机无操作超过5分钟软关机；充电异常和电池/主板过温恢复需人工请求。普通提示音可静音，低电量/故障提示不可静音；首次必要校准允许OLED引导与人工确认。首版只做原地平衡，整体紧凑，用户自制3D打印两轮/电池固定底座；后续手机App经ESP32和UART发送控制数据。OLED现为0.96英寸I²C SSD1315；主板BTB候选HC-PBB08-2-16-F-H4.0-G1-R-P-04，配对合高/封装仍待核查。电机授权先做情景估算，不将估算视作额定值；电芯型号仍未确定。按键/LED分配已委托提出方案，软件可参考SimpleFOC/ODrive但未选定。USB自动充电改为“简单可靠才考虑”的条件评估，G431具BC1.2能力不等于已验证整机自动启充；当前仍以默认关闭、菜单手动启充为实现基线。完整已确认范围、交互提案与原厂证据见[首版功能补充与交互草案](../project/interaction-and-first-build.md)。
