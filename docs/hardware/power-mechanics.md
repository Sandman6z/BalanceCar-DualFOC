# 电源、机械与标定

## 电源

3S 锂电为当前系统基线。独立 Buck 负责系统供电，DRV8323S 不带额外集成 Buck；独立 Buck 不能默认吸收回生能量。Buck 完整型号、输入输出、持续/瞬态电流、静态功耗和启动顺序尚缺。

电池包、BMS、充电器和主板各自职责尚未确定，包括单节监测、电量、温度、充电状态/使能、软关机、待机和唤醒。不能默认这些都已计入引脚预算。

满电制动、BMS 断开与回生抬升需统一设计母线电容、钳位或耗散及故障策略。是否加受控泄放电阻、阻值功率和控制接口均未定。

## 机械与板卡

当前规划：一体式主体框架定位电池、电机、编码器板和主 PCB；三节 18650 横向并排、位于 PCB 下方。PCB 不承担电机轴线和编码器气隙定位。

板卡规划为一块主 PCB、两块相同的 AS5047P 编码器板和一块可选扩展板；基础平衡和电机控制不依赖扩展板。当前尚未取得机械图或 PCB 原件。

标定需覆盖电流零点、相序、电角度与极对数、左右轮方向、编码器磁铁和气隙、IMU 坐标与静止零偏、车身直立零点。

## 待确定参数

电机完整型号、轮径、整车重量、速度、加速度和小坎目标待确认。连续/峰值相电流、PWM 频率、死区、保护阈值、保险及 BMS 规格须据此计算并验证。驱动器耐压高不代表可以提高 3S 电池允许电压。
