# 首版功能补充与交互草案

日期：2026-10-27。用户逐项回复为决定依据；本页区分已确认行为、受委托提出的交互方案和仍待验证的工程事项。未实现固件或完成样机测试。

## 本轮已确认

1. MCU意外复位、看门狗复位或按NRST后保持待机，检查通过后按功能键请求恢复；不等同于仅电池正常长按开机，后者保留检查通过自动平衡。
2. 两个功能键由助手先提出具体方案，见下表，尚非用户逐项确认的按键定案。
3. 电池供电时，待机无操作超过5分钟自动软关机；平衡运行不算待机。USB连接时保留核心供电和菜单，不由该定时切断USB核心。充电不作为电池空闲待机超时关机处理；具体事件优先级待实现验证。
4. 充电输入掉电、超时或温度异常等导致停止后，不自动重试充电，需菜单手动重新开启且通过检查。正常充电完成仍按已定流程关闭CHG_EN、显示完成并待机。
5. 电池/主板等非驱动部分过温，停止相关功能并提示；温度恢复后仍需人工恢复。电机驱动相关故障继续执行更高优先级的双电机禁能及人工恢复约束。具体检测点、门限、回差、停机顺序与可恢复条件待设计。
6. 蓝绿0603 LED及四颗WS2812用途委托助手设计，以下为首版分配方案。
7. 允许开关机/恢复等普通短鸣并提供普通提示音静音；低电量和故障提示不得被静音。蜂鸣器选型原则：供货充足、价格便宜、声音够用后尽可能小，不再预设12×12 mm或压电型为必选。
8. 首次需要的电机对齐或IMU静止校准，可按OLED提示固定车身、保持静止并人工确认。正常开机流程不额外增加菜单确认；校准电机动作需单独提示并设计受限驱动流程，不允许USB插入直接触发。
9. 电脑USB和普通5 V充电头均可能使用，没有充电速度目标。当前可落地基线仍为插入默认CHG_EN关闭、菜单手动启充。用户允许在识别简单可靠时考虑自动充电，不再绝对排除端口识别；自动启充的适用端口和全部互锁尚未冻结，不能仅凭未枚举就自动充电。
10. 首版仅做原地平衡，不要求主动前后移动或转向。后续拟通过手机App→ESP32无线连接→UART→主控发送移动指令；平衡及双FOC继续在独立主控本地运行，扩展板缺省不装不影响首版。
11. 电机仅明确2204云台类型，无完整型号。授权助手先做参数情景估算；估算不构成该电机KV、绕组、电阻/电感、安全电流、扭矩或额定功率证明，不移植航模2204参数。功率器件、限流及回生选值冻结前仍需核实/测量。
12. 用户自行3D打印连接两轮并固定电池的底座，整体自制；不再询问是否购买成品底座或成品电池包。保留既定三节18650电气串联、机械并排的规划；电芯品牌/型号、容量和允许充放电规格仍未确定，自制底座不代替电芯选型。
13. 整体尽量紧凑，目前没有速度、续航、越坎或爬坡目标，以能够稳定平衡为首版目标；先前总体方案的小坎/急加减速愿景不作为首版验收指标。
14. OLED更新为0.96英寸、I²C、SSD1315，取代先前SSD1306描述；模块供电、分辨率、引脚顺序、上拉、初始化及实际电流需按具体模块核实。PCB无硬性尺寸约束。主板BTB候选HC-PBB08-2-16-F-H4.0-G1-R-P-04，与既定扩展侧HC-PBB08-2-16-M-H1.0-G1-R-P-04配对能力、合高、脚号方向及功率接点待核查，尚未定案。
15. 无指定软件框架，可参考SimpleFOC或ODrive；两者是评估参考，不视为选定依赖、整套移植或已证明适配双电阻/3PWM/双FOC。软件路线与最终MCU应联合验证。

## 两个功能键的具体提案

独立电源键仍只负责约2秒长按开关机，短按无动作；NRST只负责复位。以下是可评审方案，尚未实现。

| 当前状态 | K1短按 | K1长按 | K2短按 |
| --- | --- | --- | --- |
| 电池待机主页面 | 切换状态页/进入菜单 | 返回主页面 | 请求开始平衡，检查通过后使能 |
| 菜单 | 下一项/切换选项值 | 返回上级，不提交当前修改 | 确认当前项/提交 |
| 平衡运行 | 切换只读状态页 | 返回状态首页 | 请求退出平衡并进入待机 |
| 锁定故障或自动重试耗尽待机 | 查看故障详情 | 返回故障首页 | 请求清故障/恢复，条件不满足则保持禁能并显示原因 |
| USB调试待机 | 查看/进入调试菜单 | 返回调试首页 | 确认菜单操作；运行使能必须明确选中调试菜单中的启动项 |

K2的启动/恢复只由新的按下事件触发；同一次按住、按键抖动或状态切换不能重复生成启动请求。平衡运行时K2停止动作优先于页面导航。USB模式不能借通用恢复键绕过菜单显式使能；充电时启动请求被互锁拒绝。K1长按时长及消抖由工程设计，不复用电源键的开关机计时。

待机5分钟计时建议：进入电池待机开始计时，实体按键或有效用户操作重置；进入平衡退出此计时。周期遥测、故障日志和自动重试内部事件不算用户操作，避免永久延长待机。此计时细节为实现提案。

## 指示与提示音的具体提案

| 器件 | 分配方案 |
| --- | --- |
| 蓝色0603 LED | USB VBUS有效时亮，表示USB接入，不等同于枚举成功或正在充电 |
| 绿色0603 LED | 电池/USB核心待机慢闪，平衡稳定时常亮，故障时快速闪烁；实际GPIO及亮度待核算 |
| 四颗WS2812 | 待机低亮度、平衡绿色、充电橙色、完成绿色短提示、低电量黄色闪烁、故障红色闪烁；故障显示优先，不掩盖OLED文字 |
| 普通提示音 | 开关机、按键确认及恢复成功短鸣；菜单可关闭 |
| 强制提示音 | 低电量及故障按不同节奏提示，普通静音设置不影响；节奏/占空比待调试，避免持续鸣叫干扰交互 |

WS2812亮度和动画可用软件限制，硬件峰值负载仍按选定版本及可达配置核算。普通LED用途变为本提案后仍暂留两路GPIO，不擅自改为硬接电源减少IO预算。

## USB识别核查与条件边界

ST STM32G431数据手册DS12589 Rev6第3.34节（PDF第42页）明确：USB PHY内置符合BC1.2的电池充电检测。若最终仍用该系列，可评估利用已有外设检测SDP/CDP/DCP，无需先假设增加专用识别芯片。

但BC1.2识别的是端口类型，不是可靠识别“电脑机箱/墙上充电头”这类物理设备。CDP同时支持数据和充电；USB枚举超时、断数据线也不能单独证明是专用充电头。Type-C的CC电流声明与BC1.2还需分别核查。检测完成及允许电流不能代替系统限流、逻辑/扩展负载与充电功率预算。

可继续评估的最小自动策略：仅对明确识别的专用充电端口，结合有电池、温度正常、电机未运行且已禁能、无故障及输入预算允许等条件考虑自动启充；数据端口或识别不确定时保留菜单手动。若插USB前正在平衡，必须继续执行既定的退出平衡且不自动充电规则，不由该候选策略覆盖。此自动策略尚未定案或测试，当前实现基线仍为菜单手动。

依据：[STM32G431数据手册](https://www.st.com/resource/en/datasheet/stm32g431rb.pdf)、[Microchip BC1.2端口与检测说明](https://developerhelp.microchip.com/xwiki/bin/view/applications/usb/power-delivery/battery-charging/)。

## BTB及后续无线控制核查

厂家公座系列图与母座系列图提供HC-PBB08-2-N-M/F-HX-G1-R-P-04系列依据；目前尚未完成准确M-H1.0与F-H4.0配合截面和公差核查，不用两处H数字相加宣称合高，也不据渠道泛化的合高列表冻结PCB。还需核对端子/镀层图纸版本、定位柱、两面脚号映射与电源地接点；明确型号后校验封装并试插。

资料：[HCTL公座系列原厂图](https://www.hctldz.com/static/upload/2026/01/29/202601298345.pdf)、[HCTL母座系列图（LCSC托管）](https://datasheet.lcsc.com/datasheet/pdf/1f2bc63b424e11ba595813a8850d68e5.pdf?productCode=C41421151)。两份图纸的材料/电气描述存在版本差异，不能只因系列相同宣称已完成准确配对验证。

手机→ESP32→UART→主控作为后续指令架构可行方向；ESP32-S3官方UART文档提供外设通信依据，未验证本车App/协议。建议无线链路仅发送目标速度、转向和状态请求，主控保留运行授权、限幅、指令有效期与失联处理。扩展板上线/重启或UART噪声不得自动产生运行许可；帧格式、校验与超时策略留待后期运动功能设计。

依据：[ESP32-S3官方UART说明](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/peripherals/uart.html)。

## 蜂鸣器下一步

按“现货与价格可接受、声音够用，再最小化”比较国产小型电磁与压电器件，需同时统计驱动器件、功耗、占板和外壳声孔，不只比较蜂鸣器本体面积。此前CPT-1203-03-SMT-TR仍只是候选，不默认定为12 mm压电器件；微型电磁器件也不能默认由MCU或现有LDO直接驱动。

示例：Same Sky CMT-0503-75-SMT-TR原厂资料对应5×5 mm级外驱电磁器件，可作为小尺寸能力对照，未选定。2026-10-27检索的DigiKey和Future页面均显示无现货，且有大包装/交期限制，不符合本项目“供货充足且便宜”的优先条件，不能因尺寸小就推荐定案。

依据：[Same Sky原厂手册](https://www.sameskydevices.com/product/resource/cmt-0503-75-smt-tr.pdf)、[DigiKey渠道状态](https://www.digikey.com/en/products/detail/same-sky-formerly-cui-devices/CMT-0503-75-SMT-TR/10326208)、[Future渠道状态](https://www.futureelectronics.com/p/passives--sound-devices--buzzers/cmt-0503-75-smt-tr-same-sky-1191723)。供货状态会变化，下单前重查。

新增小尺寸候选FUET-5020（未选定）：福声原厂页面及厂家承认书给出无源电磁、4 kHz、额定3 Vo-p、2～4 Vo-p工作范围、额定条件最大110 mA、10 cm最小75 dB。承认书表列5×5×2 mm，渠道有2.2 mm高度记录且承认书内部出现FST/FUET不同标记，冻结焊盘前须核实准确供货版本。小体积不等于低功耗，需驱动级及3 V等级供电核算，不直接接MCU或5 V。JLCPCB检索页显示该料暂无库存，不把其他渠道搜索库存当作可靠小批供货证明；保留候选并继续比较，不宣称声音已在本车外壳内验证。

资料：[福声原厂产品页](https://www.fsdzsz.com/product/2_107)、[厂家承认书（LCSC托管）](https://datasheet.lcsc.com/lcsc/2410121831_FUET-FUET-5020_C391029.pdf)、[JLCPCB供货页](https://jlcpcb.com/partdetail/FUET-FUET5020/C391029)。

2026-10-27蜂鸣器专项说明已建立，见[蜂鸣器选型说明](../hardware/buzzer-selection.md)。新增MLT-5020与9 mm压电对照；本轮LCSC索引对FUET-5020显示零售库存线索，与此前JLCPCB贴片库存不是同一口径。供货与准确版本仍需复核，所有型号维持候选。
