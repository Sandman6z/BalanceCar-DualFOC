# 待确认清单

更新日期：2026-10-22。本项目仅涉及 Balance Car。

## 讨论入口

| 优先级 | 问题 | 影响 |
| --- | --- | --- |
| 1 | 首版必须实现哪些功能，怎样验收？ | 确定资源预算和开发范围 |
| 2 | 电机完整型号、轮径、重量、小坎和加减速目标？ | 决定电流、功率、采样和保护设计 |
| 3 | 双路 FOC 使用什么软件路线？ | 核对 ADC、PWM 触发、执行时间和内存 |
| 4 | 主控最终型号与全功能引脚表？ | G431RBI6 暂列候选，后续可能更换 |
| 5 | Buck、电池、BMS、充电与回生各由谁负责？ | 完成电源树、接口及故障工况设计 |
| 6 | IMU 是否正式选定 ICM-42688-P？ | 明确接口、中断及固件驱动 |
| 7 | 开机、校准、直立使能、摔倒、失联和故障后如何恢复？ | 完成状态机及安全禁能设计 |
| 8 | MOS、采样电阻、CSA 增益、保护和死区如何设置？ | 依赖电机参数、器件计算及实测 |
