# 当前选型状态

更新日期：2026-10-22。本文记录当前讨论结果；“已选定”不代表原理图或样机验证通过。总体架构见[整车总体方案](../architecture/overall-plan.md)。

| 内容 | 当前结论 | 状态与边界 |
| --- | --- | --- |
| 目标 | 桌面双轮平衡车，轻载、小功率、不载人，成本敏感 | 已明确 |
| 控制 | 独立 MCU 集中运行两路 FOC、姿态和平衡控制 | 已确定；最终 MCU 待选 |
| MCU | STM32G4 为当前方向，STM32G431RBI6 暂列候选 | 未冻结，允许换型 |
| 栅驱 | DRV8323SRTAR×2，SPI、内置三路 CSA、无系统 Buck | 已选定 |
| 功率桥 | 左右各六颗外置 N-MOS，共十二颗 | 架构确定，MOS 待选 |
| PWM | 按两台电机总计 6 路、每路 3PWM 预算 | 时序/软件验证待完成；非总计 12 路定案 |
| 电流采样 | 每电机两个低侧采样电阻，共四个 ADC 输入；MCU 重建第三相 | 已选择双电阻；阻值、CSA 增益待算 |
| 编码器 | AS5047P×2，SPI，共享总线独立 CS | 已选定；ABI/ABZ/UVW 不使用 |
| IMU | ICM-42670-P，四线 SPI＋数据就绪中断 | 已选定，替换旧文档 ICM-42688-P 倾向 |
| 显示 | SSD1306 I²C OLED | 已确定 |
| 指示 | 四颗 WS2812 串联占一路数据 | 已确定；不加普通 LED、蜂鸣器 |
| 按键 | 一个 NRST 复位键＋两个功能键 | 当前采用 |
| 通信扩展 | ESP32 扩展板提供 Wi-Fi/蓝牙，与主控 UART 通信 | 已确定；暂不加 CAN 和遥控器 |
| USB | 保留原生 USB 数据接口，Type-C 同口取 5 V 充电 | 当前采用；电源路径待设计 |
| 电池 | 3S 18650 为当前基线 | 电芯具体型号、允许工作区间与电机性能待验证 |
| 充电 | IP2326 标准版为首选，CN3303 为低价备选 | 有源资料与商业产品依据；未做本车样机验证 |
| 充电控制 | MCU 一个 EN GPIO，OLED 菜单手动开启/停止，默认关闭 | 已明确，不做自动识别电脑/充电头 |

| BM3451SMDC-T28A | 不采用 | 用户明确排除，资料和调试条件不满足要求 |
| 系统稳压 | 独立 Buck，生成系统所需电源 | 具体型号、能力与电源预算待补齐 |
