- 主板TPS563201DDCR输出5 V，主板3.3 V采用LDO方向；ESP32-S3-WROOM-1-N16R8扩展板另用TPS563201DDCR将主板5 V降为3.3 V，扩展板不另设软件电源开关。
- SSD1315 I²C OLED、四颗WS2812、蓝绿0603 LED各一、FUET-8530-3.6V无源电磁蜂鸣器、两个功能键、独立电源键、NRST键。
- 既有开关机、USB、电机/充电互锁及故障恢复行为继续按[电源与运行模式](../hardware/power-operating-modes.md)和[决策记录](decisions.md)执行。

### STM32G系列重新收敛（2026-10-28）

用户询问G系列是否没有合适型号。更正此前将“至少256 KB RAM”当成筛选起点的过度预算：该数值不是用户要求，也非现有单色SSD1315＋LVGL菜单的必要门槛。G473/G474的512 KB Flash＋128 KB RAM，以及G491的512 KB Flash＋112 KB RAM，均应保留为有合理余量的工程候选，实际编译/内存池/控制时序仍需验证。未明确更换为大分辨率彩屏，不以彩屏预算排除G系列。

推荐先以STM32G473VEH6（TFBGA100、0.8 mm、512/128 KB）作为本车技术首选提案，理由是较宽松IO、足够进行单色LVGL评估的内存及已取得得捷现货记录；US$12.06单颗/US$9.385十颗档不属于低价承诺，国内便宜货源尚未核实。STM32G491REI6（UFBGA64、0.5 mm、512/112 KB）作为替代，得捷中国含税单颗78.90元/十颗61.049元，IO仍需精算。G474VEH6资源同样可以评估，但本轮得捷渠道缺货，不凭型号性能宣称好买。尚未获用户冻结具体型号。

H743VIH6仅作被中断的跨系列调查，不是已经完成采购验证或已选定的新主控；继续优先在STM32G候选中完成资源与国内散料比价。

### LVGL需求变更与资源预算（2026-10-28，原预算见后续更正）

用户明确“OLED我准备跑个LVGL，所以稍微大些”，接受更换MCU系列。按上下文将“稍微大些”理解为MCU资源余量，不擅自更换现有0.96英寸SSD1315 I²C OLED；具体屏幕分辨率仍待核查。撤下G431优先地位，之前20 KB RAM/100 KB Flash的精简预算仅保留为旧场景分析，不能作为新需求够用的结论。

新工程筛选建议至少512 KB Flash、256 KB RAM，优先1 MB Flash/512 KB RAM，有足够IO映射及双电机采样资源；这是留余量的设计目标，不是LVGL官方最低要求或用户硬性容量门槛。最新厂家范围仅STM32，GD32已排除；允许比较STM32的F4/F7/H7及其他合适系列，不因内存参数直接推荐未经比价、库存与采样核查的型号。G473VEH6等512 KB/128 KB的STM32候选仍可评估，但需说明资源余量和价格取舍。

LVGL支持1位单色显示；若实际模块为128×64，纯像素全屏仅1024字节，但LVGL对象、样式、字体、内存池、驱动转换及通信另占空间。不能因帧缓冲小就断言128 KB Flash/32 KB RAM能宽松容纳整车软件。字库按实际字符集裁剪，不能承诺1 MB可装任意完整中文字体。

首轮新预算示例：LVGL动态池32～64 KB；双FOC/姿态/校准16～32 KB；USB/UART/SPI及调参缓存16～32 KB；主栈/中断栈及必要后台16～32 KB；屏幕缓冲/转换暂留4 KB。以上分组需实现后消除重复计数，不是实测占用，剩余留调试与扩展。Flash以程序＋所需字体/图标/参数不超过器件约70～75%为目标，LVGL版本与控件配置编译后调整。

保持电流环最高实时优先级，LVGL运行于后台或低优先级任务；I²C刷新使用可让出CPU的分段/异步方式，菜单绘制不进入电流ISR，避免刷新或动态分配阻塞双FOC。是否用RTOS留到调度实现，不因LVGL自动增加RTOS依赖。

官方依据：[LVGL硬件需求](https://lvgl.io/docs/open/9.5/introduction/requirements)、[LVGL 9.2单色显示接口](https://lvgl.io/docs/open/9.2/porting/display)。具体移植版本尚未冻结；SSD1315页布局与LVGL I1排列需驱动层适配，不能未经验证照搬其他OLED驱动。

## 3. 电源树与开关机

本提案将电池侧核心供电从电机运行开关前分出，以落实已经确认的USB下关闭运行供电、保留核心，以及拔USB后电池待机的行为。它是对现有功能块的实现细化，尚非接线图。

```text
三节电芯 → CW1244保护输出 PACK_PROTECTED
  ├─ 核心电池锁存开关 → TPS563201 5V_BAT → 核心电源MUX
  └─ 电机背靠背开关 → VMOTOR → 双功率桥与DRV8323
                          ├─ 共用制动电阻＋低侧MOS
                          └─ 独立5V_BRAKE → 比较器/必要缓冲
USB VBUS → ESD/输入限流/反灌保护
  ├─ 核心电源MUX → 5V_SYS → 主板LDO/OLED/灯/扩展板
  └─ IP2326充电输入 → 受保护充电路径 → 电池
```

- IP2326接保护芯片规定的充电端；低侧保护的B−与P−不得混用，不能用USB地或调试地绕过保护MOS。
- 核心MUX优先USB；电池锁存保持开启时，拔USB可转电池。USB接入本身不置位电池保持或电机运行授权。
- 独立电源键采用基础分立锁存＋MCU计时方向，不加8秒强关芯片。按下可临时唤醒核心以测量按住时间；未满2秒不进入用户开机状态、不接通电机电源，松开后撤销临时供电。此内部唤醒不构成“短按开机”。开机界面与运行授权仅在长按成立后出现。
- USB供电时由MCU读取长按；关机撤销电机运行电源和电池核心保持，保留USB核心。菜单重新打开运行供电时同步恢复电池核心保持，随后拔USB进入电池待机。
- MCU复位必须清除运行授权，电机开关/驱动输入默认关断；保存核心供电保持可以独立于复位，以便显示复位原因。硬件锁存置位来源须能区分按键开机与USB启动。
- 运行关机先撤销力矩、确认禁能，再切运行电源。制动电阻及5V_BRAKE始终接在功率桥同侧，电池/BMS断开后仍能处理母线回生；外力转轮不得反向唤醒主控。
- 蜂鸣器3.3 V峰值按线圈、驱动和去耦计算，与LDO热预算一起评估。若ME6211不够，优先改用热性能更好的LDO封装，保留主板5 V→LDO→3.3 V结构；若仍不能满足，再列出增加Buck等改动的成本供修改，不强行保住原候选。
- 本版核心5 V路径按1 A级负载能力核算，扩展插入瞬态单列；这是设计额度，不是USB授权取电电流。最终外围值需原理图级计算。

## 4. 电池、充电、保护与检测

不要求用户现在提供电芯型号。容量以2500 mAh/节作为软件界面和能量估算占位，不能标成真实容量；3S1P约27 Wh（按3.6 V/节计算），续航待实际功耗测量。不要按总压线性换算精确电量百分比，首版优先显示电压与低电量状态。

| 项目 | 本版建议 | 使用限制 |
| --- | --- | --- |
| 充电操作 | 首版仅菜单手动开启；插USB默认关闭 | 自动端口识别推迟，减少首版条件分支 |
| 充电电流目标 | 先按电池侧0.5 A做方案功率核算 | 不是已允许设置；需验证电芯、IP2326可编程范围、终止电流及输入预算 |
| 输入功率 | 满电0.5 A约6.3 W；按85%效率示例，USB侧约1.48 A，另加系统负载 | 不能由“USB 5 V”推断一定能提供；85%仅为情景效率 |
| 普通电脑USB | 枚举/源能力及逻辑负载不满足时禁止启充，显示原因 | 500 mA输入不能同时许诺0.5 A电池充电；未枚举不等于充电头 |
| 充电完成 | 优先IP2326可靠状态输出，结合电压与超时/故障分类 | 不把EN关闭、VBUS丢失或温度停机当作充满；状态脚按原手册核对 |
| 电池低电量预警 | 总压≤10.5 V持续2秒，回差0.3 V作为首轮软件起点 | 未经实际电芯、逐节电压与负载压降验证，不作为正式保护值 |
| 低电量停机 | 总压≤9.9 V持续1秒，受控停机后软关机作为首轮起点 | 任一单节异常优先；总压不能保护弱电芯，不等待BMS切断 |
| 温度检测 | MCU独立电池NTC、功率区NTC各一；BMS温度输入独立设计 | 建议10 kΩ/B3950作为采购方向，精度/曲线/安装位置需核对 |
| 温度起点 | 充电仅10～40℃、电池运行≥50℃停机、功率区≥75℃停机 | 仅工程初值，实际电芯若更严则收紧；恢复到45℃/60℃后仍需人工请求 |
| 相电流与电池电流 | 分别计算；电池侧通路暂按5 A级进行铜宽/连接器情景预算 | 不是批准从未知电芯取5 A，也不是CW1244保护电流定值 |

CW1244ALBS完整后缀资料不足，本版保留已选芯片，预留逐节测试点、独立保护MOS及均衡电阻位置。其过充/过放/过流、NTC、均衡电流、延时和恢复方式不编造数值、不移植其他芯片电路。下一阶段取得完整手册后才能形成该模块可投板原理图；当前能完成接口和测试要求。

充电限流应对USB所有分支的总输入负责。固件拒绝超预算请求之外，还需硬件输入保护；准确限流器型号取决于是否需动态调流、压降和成本。扩展板插上随5V_SYS供电，因此USB独立供电预算必须包含已安装扩展板，不靠新增扩展板开关解决超预算。

## 5. 功率桥、采样与回生的计算起点

- 每路双采样10 mΩ、增益20，输出偏离零点为0.2 V/A；若有效双向输出余量按±1.0 V预算，则约±5 A测量范围。真实范围要扣除CSA/ADC摆幅、零偏、误差和瞬态，不能把±5 A视作电机安全电流。
- 电阻以5 A时I²R=0.25 W作为发热情景，考虑开关波形、脉冲和热降额后筛选1 W级器件；未完成准确料号和PCB热计算。
- 电机台架先从约0.3 A的Iq限幅起步，只在核对绕组电阻、静态损耗和温升后加大；0.3 A也不是未知电机的安全保证。阻值/电感/极对数、编码器方向与电角零点需要测量。
- 推荐20 kHz中心对齐PWM，两路以确定相位关系同步；初版每路电流环10 kHz，ADC注入触发避开换相和死区。采用采样窗口约束/占空限制，窗口无效时不把失真数据送入PI；低速平衡也必须验证重建。
- MOS栅阻从4.7 Ω预留起步，驱动电流从较小档台架调整；不得据此冻结VDS保护门限或过流反应，须看VGS/VDS波形及开关损耗。
- 回生建议目标：13.4 V导通、13.0 V释放，仅为迟滞设计中心。以基准最坏误差、失调、分压容差、输出摆幅与启动动态计算边界后再用；不把旧门限或本数值当作用户定案。
- 共用电阻首轮评估10 Ω、25 W级脉冲型：13.4 V时约1.34 A、18 W瞬时耗能。25 W通常有安装/散热条件，裸板不等于可连续25 W；若双电机回生超过1.34 A，此阻值不能保证钳位，需减小阻值或降低运行能量。
- 制动MOS可先复用CSD17577Q3A做驱动负载评估；按实际5 V驱动栅电荷计算切换与损耗，比较器直驱不合格则装缓冲。制动电阻远离电芯、IMU与塑料，预留外置安装接点。
- VMOTOR总电容先按470 µF/35 V低ESR加每桥局部陶瓷做布局额度；电容仅缓冲，不能替代耗能支路。依据允许过冲和ΔV≈IΔt/C核算，检查断电后外力转轮的5V_BRAKE启动速度。

| 控制结构 | 互补滤波估计俯仰，轮速/有限位置保持给出小角度目标，姿态PD输出两轮公共Iq，电流PI驱动；左右差速仅做必要抑制，不加入手机运动功能 |
| 性能门槛 | 100 µs电流周期内，两电机计算＋采样调度目标≤60 µs；测最坏时间，过载则降后台刷新或调整频率 |
| 资源余量 | 编译后目标Flash/RAM至少保留20%；达不到则精简缓存/后台功能并重新评估MCU，不能仅为保G431删保护 |

此处是功能分配，不是完整可投板引脚表。先用CubeMX/参考手册核对全部复用，再产出带管脚号的引脚表；蜂鸣器和WS2812定时器/DMA、温度ADC、软开关和充电状态不得漏计。不能由“39脚预算”直接宣布64引脚可用。

交互直接采用已有草案：K1短按翻页/下一项，长按返回；K2短按确认/电池待机启动/运行停止/故障后请求恢复。USB模式启动仅从明确菜单项执行。K1长按暂取0.8秒、消抖20 ms；独立电源键仍为2秒，NRST只复位。四颗WS2812低亮度提示待机、平衡、充电、低电量和故障，故障优先。普通短鸣可静音，低电量/故障不可静音。

BTB继续按既定公座和候选母座核查，不仅凭H数字相加确定合高。16接点初步功能预算：5 V×3、GND×5、UART TX/RX×2、预留×6；最终接点分配先看每触点电流及两侧脚号镜像。UART预留串阻和断电隔离器件位置，不宣称热插拔已合格。

## 7. 故障与恢复参数建议

| 事件 | 首轮参数建议 | 行为 |
| --- | --- | --- |
| 摔倒判定 | 俯仰绝对值>35°持续100 ms，或更大倾角/异常角速度触发快速停机分支 | 禁能；倾倒角度更大时不能等待普通去抖，快速门限由台架确定 |
| 扶正恢复 | 倾角<8°、角速度<10°/s且数据有效，持续1秒 | 必要检查后以约0.5秒受限斜坡恢复；依照已确认授权与互锁 |
| 摔倒重试 | 30秒内最多3次，连续稳定平衡10秒清计数 | 超限待机，K2重新请求；人工请求只在检查通过后清计数 |
| 传感器失联 | 编码器连续校验/传输错误或数据超龄1 ms；IMU数据超龄10 ms作为台架初值 | 任一关键传感器无效，双电机禁能；不持续使用陈旧角度运行 |
| 传感器恢复 | 连续有效数据500 ms，姿态重新建立、编码器一致性/电流零偏检查通过 | 自动受限恢复；30秒最多3次，稳定10秒清计数，超限转人工 |
| 重试计数 | 摔倒、传感器分开计数，另加合计30秒3次重启预算 | 防止两类故障交替绕过次数限制 |
| 驱动故障 | nFAULT、电流采样异常/功率桥相关故障 | 立即撤销双侧许可并锁定；硬件故障联动优先，K2请求且检查通过才恢复 |
| 意外复位 | 包括NRST、看门狗、欠压复位 | 待机，K2人工请求；不得等同电池正常长按开机 |
| USB接入/拔出 | 一经检测即撤销自动恢复资格，受控退出并禁能 | 插USB绝不产生启动授权；拔USB电池可供时待机 |
| 充电异常/过温 | 关闭相关功能并提示，条件恢复仍等待人工 | 不自动重启充电或平衡 |
| 低电量停机 | 按第4节起点核算与调整 | 撤销运行许可，禁能后软关机；回弹/BMS恢复不自动启动 |

所有角度、电压、延时、次数和环路频率都是建议初值，需实测。故障互锁优先于重试，USB菜单授权、充电、关机、低电量和驱动锁定均不可被自动恢复覆盖。控制器增益不能在未知电机、质量和重心时编造；软件先提供受限台架调参，再装车整定。

## 8. 机械与验证交付

底座由用户3D打印。建议电池并排固定在下方，PCB独立支柱安装，轮轴保持同轴；编码器板靠电机轴固定，先以准确磁铁规格和气隙要求设计支架，PCB不承担轴承定位。可先用60 mm轮径、0.5 kg整车质量作扭矩情景核算，实际尺寸/质量以用户底座为准，不转为硬性要求。

实施顺序：电源路径与IO映射→禁能最小系统→单电机低能量FOC→双电机时序→回生与故障注入→装车平衡。正式充放电和电机加载前，核实实际电芯、电机参数。首版验收建议为平整桌面连续平衡5分钟、无控制超时/异常复位；USB插拔不意外启动；充电/平衡互锁有效；摔倒、失联、驱动故障、低电量按已定规则工作。

本轮交付为方案文件。尚无完整原理图、准确封装库、最终引脚表、固件工程及台架结果；不把本页当作直接接线/投板BOM。下一步优先落实电源开关/MUX完整电路、G431资源映射、CW1244完整资料和LDO负载热预算，这些是冻结首版PCB的依赖，不要求逐个电阻再次征求用户批准。
