# 控制与分阶段验证

本页维护当前控制设计与验证要求，尚未实现固件或执行样机验证。

## 软件尚待确定

- ST 参考方案或自行实现的双 FOC 软件路线及对应支持范围。
- 两电机 PWM、ADC 触发、采样窗口、编码器读取和 SPI 配置的调度。
- 电流环、速度环、姿态估计和平衡环的频率、延迟、限幅与执行时间。
- G431 的 Flash/RAM 实际占用，以及通信和调参缓存的预算。

## 启动和故障流程

总体方案已要求：上电保持功率禁能，配置并回读驱动寄存器，无电流时校准采样零偏；SPI 配置失败不能进入平衡运行。

故障应记录来源、时间、运行状态及寄存器。严重单侧驱动故障触发整车协调停机；传感器失联、摔倒、低电量、MCU 复位和掉电的具体动作仍待定义。保护、软件限流、热限制不能混为一个阈值。

恢复需确认故障消失、按手册清除或重置、必要时重配并回读、自检和重新授权。不能仅见 nFAULT 恢复高电平就自动恢复力矩。BKIN/安全禁能硬件联动方案仍待核对。
