# 桌面双轮平衡车整机方案

更新：2026-10-30。此文件维护整机范围、决定状态、运行方式及下一步工作。硬件、软件、结构分别只维护一份主文档；不再保留多份当前选型快照和重复决策表。

## 1. 当前目标与完成情况

桌面双轮平衡车，轻载、小功率、不载人，首版实现原地稳定平衡。整体尽量紧凑，但PCB尺寸、球数没有硬性限制。首版不要求主动移动、转向、速度、续航、爬坡或越坎；后续手机App经ESP32/UART发送运动指令。

目前完成方案讨论、器件资料核对、MCU资源工程编译/ARM仿真和其他硬件的桌面计算审查。没有新版完整原理图、PCB、完整运行固件、结构CAD或样机验证。文档中的“已定”指用户已确认，“提案”指供后续修改的工程建议；估算数值不是额定值、实测值或可直接投板BOM。

## 3. 已确认的运行方式

| 场景 | 核心/电源 | 电机/充电 |
| --- | --- | --- |
| 仅电池长按开机 | 锁存供电、初始化 | 必要检查通过后自动进入平衡，不再要求菜单确认 |
| 仅电池长按关机 | 完成停机后释放供电保持 | 先退出平衡、禁能，再关闭运行供电；保留必要回生回路 |
| 仅USB、无电池 | 核心/OLED/VCOM可运行 | 电机和充电均禁止 |
| 电池＋USB，未充电 | 核心/OLED/VCOM保持 | 默认禁能；仅调试菜单明确操作可启动平衡 |
| 正在平衡时插USB | 保持交互，进入调试 | 受控退出并禁能，不自动充电 |
| USB拔出且电池可供核心 | 电池保持生效时转电池待机 | 即使此前菜单运行，也退出并禁能，不自动恢复力矩 |
| USB连接时长按关机 | 保留USB核心/OLED/VCOM，关闭电机运行供电及电池核心保持 | 不能只用PWM禁能代替运行电源关闭；充电仍可由菜单控制 |
| USB下从菜单重新开运行供电 | 同时恢复电池对核心的供电保持 | 随后拔USB进入电池待机，可手动启动，不自动平衡 |
| 手动启充 | 检查输入能力、电池、温度与状态 | 先撤销电机许可并确认禁能，再启CHG_EN；充电期间互锁 |
| 正常充满 | MCU关闭CHG_EN，显示充电完成，待机 | 不自动恢复平衡；故障停止不得显示充满 |
| 电池待机无操作超过5分钟 | 自动软关机 | 平衡运行、充电不作为该空闲超时；USB核心不被切断 |

任何USB接入、抖动、枚举、复位、母线恢复或BMS恢复均不能生成新的电机运行许可。仅电池的正常长按开机来源需与USB唤醒和意外复位区分。

约8秒硬件强关功能已取消，不增加专门计时/按键芯片；MCU死机无法正常关机时接受取下电池，核心若仍由USB供电还需拔USB。

自动识别充电头仅保留“简单可靠才考虑”的后续评估许可，当前不实现自动启充；不将未枚举判成充电头，也不自动启用PD/QC。

## 4. 已确认的故障行为

- 摔倒：双电机停机；扶正且检查通过后有限次数自动恢复，失败超限进入待机，按一次功能键可重新请求。
- IMU或任一编码器失联：双电机禁能；数据恢复并通过姿态/角度/零偏等检查后自动恢复；反复失败采用有限重试，超限待机后人工请求。
- 任一电机驱动、功率桥或电流检测相关故障：双电机禁能并锁定，故障消失不自动重启；按功能键明确请求，故障解除及检查通过后才允许恢复。该规则优先于摔倒/传感器自动恢复。
- 意外复位、看门狗或NRST：待机，按功能键检查恢复，不等同电池正常长按开机。
- 低电量：OLED＋蜂鸣预警，继续下降后受控停机并软关机；USB在则保留核心/手动充电菜单。电压回弹和BMS恢复不构成启动授权。
- 充电异常、电池/主板过温：停止相关功能并提示，恢复正常后仍需人工请求。充电异常不自动重试。
- 任何恢复均遵守USB菜单授权、充电、关机、低电量和其他故障互锁；普通音可静音，低电量/故障提示不可静音。

具体门限、次数、时间等建议统一放在软件文档，避免各文件出现多套数值。

## 5. 后续工作与验证状态

1. G431RBI6最小工程已链接通过，52个球位（含NRST）完成数据库核查；继续完成实际总线/DMA驱动、校准和保护状态机，测双FOC最坏中断时间与电流采样窗口。采购时复核价格库存。
2. 已做3.3 V/5 V情景预算；ME6211/ME6217保留待核查候选，撤回按300 mW直接排除M5-N的依据；扩展TPS563201输入余量仍待修正，比较LDO热数据和低输入下限Buck，核对真实负载/温升。
3. 完成USB/电池MUX、核心供电保持、电机运行开关、关机顺序及独立回生控制电源电路。
4. 补CW1244ALBS完整资料，完成保护/均衡/温度/恢复电路及IP2326输入限流、终止检测。
5. 电机、电芯实物参数核对；冻结功率MOS、采样与限流、回生电阻及散热。10 mΩ＋DRV SEN_OCP最低档对应25 A，不是5 A保护；不能直接定案。
6. 增加3PWM的INL硬件锁存禁能：PF1改作ARM时钟，取消仅作阶段诊断的BAT_STAT采集，不增加MCU引脚；完善逻辑电路并验证时序。
7. 禁能上电→单电机低能量FOC→双电机时序→回生/故障注入→装车平衡。所有实机项目目前均未执行。

首版验收提案：平整桌面连续原地平衡5分钟，无控制超时或异常复位；USB插拔不意外启动；充电/电机互锁以及上述故障恢复行为正确。5分钟为验收提案，不是实测结果。
